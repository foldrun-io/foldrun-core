# Code of conduct

Be decent. Assume the other person is trying to help.

Concretely: no harassment, no personal attacks, no demanding free work.
Critique the change, not the person who wrote it. If you are asked to stop
something, stop.

This applies in issues, pull requests, commits and anywhere else this
project is discussed.

Report a problem to **hello@foldrun.io**. Reports are read by the
maintainers, kept private, and answered. Consequences run from a request to
change behaviour, through a temporary ban, to a permanent one — chosen for
what happened, not for who was involved.
